Features

Everything you need to stay consistent

Visual Content Queue

Upload your videos and images, write captions, and arrange them in a drag-and-drop queue. See everything you have lined up at a glance.

Scheduled Publishing

Set the exact date and time for each post. Yuna Poster handles the rest — your content goes live on schedule, hands-free.

TikTok API Integration

Publish directly to TikTok via the official Content Posting API. Supports video uploads with captions and cover images.

Post Tracking

Every post is logged with its status — queued, scheduled, posted, or failed. Know exactly what went out and when.

Posting Confirmations

Receive a Telegram notification after each successful publish so you always know your content made it live.

Self-Hosted

Runs on your own hardware via n8n. Full control over your data, credentials, and posting schedule — no third-party SaaS dependency.

How It Works

Three steps to automated posting

01

Upload & Queue

Add your videos and images to the content queue. Write captions, tag platforms, and set your preferred post date and time for each piece of content.

02

Schedule

Yuna Poster checks the queue on a recurring schedule. When it's time for a post, the system pulls the next queued item and prepares it for publishing.

03

Auto-Publish

Content is published to TikTok through the official API. The post is marked as published, and a confirmation is sent to your Telegram so you can verify it went live.

Built With

  • n8n (workflow automation)
  • TikTok Content Posting API
  • Telegram Bot API
  • OAuth 2.0 authentication

Platform Support

Currently supports TikTok video and image publishing. Designed for lifestyle content creators who want to maintain a consistent posting cadence without manual uploads.

Privacy & Data

Yuna Poster processes content locally on self-hosted infrastructure. No user data is stored on external servers. All API credentials are managed securely within the n8n instance.
